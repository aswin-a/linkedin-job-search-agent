# HR outreach

1. **Who:** only the job poster or hiring manager shown under "Meet the hiring team" / "People you can reach out to". Never search for others. If the user has already messaged that person, don't send again: show the earlier message and ask.
2. **Draft (< 150 words):** subject `<Role> application - <Your Name> (<city>, <availability>)` (in the subject field if there is one, else the first line); that the user applied and how; 2–3 strongest JD-matching facts from the FINAL resume; confirmed location, availability and work-mode fit; an offer to talk; name, phone, email. Facts only from the FINAL resume, Master Resume and the user's answers.
3. **Approval:** show the draft under the apply review table. `SUBMIT` approves it as shown; an edited version from the user is sent instead; `NO MESSAGE` skips it (log "HR message skipped (my choice)").
4. **Cost check** after submitting: open the composer and read the cost label.
   - "Free message" or 1st-degree connection → send
   - InMail credit or no free label → ask `SEND (uses 1 InMail credit) or CANCEL?` and wait
   - No Message button / blocked → skip and say so
5. Type line breaks with Shift+Enter, check the full text before sending, **never send twice**.
6. Log in Notes: `Messaged <name> (<title>) on LinkedIn <date, time> (free / InMail)` or `No HR contact on job page`.

Never send connection requests or follow people on the user's behalf.
